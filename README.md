🐾Tienda de mascota para todes 

 

 Descripción del proyecto de este proyecto: 

 

Tienda de mascota para todes es una tienda virtual para mascotas desarrollada en Java utilizando Programación Orientada a Objetos y Java Swing. 

 

El sistema permite: 

- Agregar productos al carrito 

- Calcular el total de compra 

- Generar pedidos 

- Seleccionar métodos de pago 

- Simular compras mediante una interfaz gráfica 

 

El proyecto implementa: 

- Herencia 

- Encapsulación 

- Polimorfismo 

- Abstracción 

- Colecciones con ArrayList 

- Manejo de excepciones 

- Interfaz gráfica con Swing
